## Selected projects

### [qzone-export-repair](https://github.com/liumengwanlhf-design/qzone-export-repair)
An offline tool for repairing text artifacts, image references, and HTML structure in old Qzone exports, with a dry-run mode and synthetic test fixtures. **Python · standard library**

### [GPT-SoVITS v2 Pro TTS Adapter](https://github.com/liumengwanlhf-design/GPT-SoVITS-v2pro-TTS-Adapter)
A personal adaptation of GPT-SoVITS's API script that accepts Luna-compatible `/tts` requests with reference-audio parameters; it requires a compatible upstream installation. **Python · FastAPI · Windows batch**

### [local-ai-ppt-generator](https://github.com/liumengwanlhf-design/local-ai-ppt-generator)
A small Windows launcher for Ollama and an existing Banana Slides installation, kept as a local workflow experiment. **Windows batch · Ollama · Banana Slides**
